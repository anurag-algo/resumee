# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes resumes, evaluates ATS compatibility, and provides personalized improvement suggestions using **Google Gemini AI**.

Demo: https://resumee-flame.vercel.app

## 🚀 Features

- AI-powered resume analysis
- ATS compatibility evaluation
- Resume upload (PDF)
- Secure Authentication (JWT & Google OAuth)
- User Dashboard
- Responsive UI
- Real-time analysis results

## 🛠 Tech Stack

**Frontend:** React.js, Tailwind CSS, Axios

**Backend:** Node.js, Express.js

**Database:** MongoDB

**AI:** Google Gemini API

**Authentication:** JWT, Google OAuth

**Deployment:** Vercel, Render

---

## 📂 Installation

### Clone Repository

```bash
git clone https://github.com/anurag-algo/resumee
cd Resumee
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🔑 Environment Variables

### Backend

```env
MONGODB_URI=
JWT_SECRET_KEY=
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GEMINI_API_KEY=
CLIENT_ORIGIN=
```

### Frontend

```env
VITE_BACKEND_URL=
VITE_GOOGLE_CLIENT_ID=
```
